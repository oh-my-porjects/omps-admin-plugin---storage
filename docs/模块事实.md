# 文件存储 模块事实

## 职责

存储公共模块，负责文件上传、资源记录、R2 配置校验和后台资源查询。

## 数据表

- `storage_resources`

## API

- `GET /api/storage/hello`：模块探活
- `POST /api/storage/upload`：上传图片资源
- `GET /api/storage/admin/resource-list`：查询资源列表
- `GET /api/storage/admin/resource-detail`：查询资源详情
- `POST /api/storage/admin/ping`：后台连通性检查
- `POST /_internal/method-call/storage`：内部方法调用
- `POST /_internal/scheduled-trigger/storage`：内部定时任务触发
- `POST /_internal/selftest/storage`：废弃自测入口

## 项目后台 V4

- `/system/resources` 是本模块唯一可导航页面，使用 `standard-list` 承载文件资源列表。
- 上传和查看详情均从资源列表通过 `open-dialog` 打开；上传使用带 `submit_action` 的 `standard-form`，详情使用 `standard-detail`。
- 本模块不再提供独立上传页、资源详情页或对应菜单。

## 实时事件

用户前端事件：

- 当前模块没有自有用户前端推送事件。

后台提醒事件：

- 当前模块没有自有后台实时提醒事件。

## 测试资产

- `tests/data.yaml` 声明本模块测试涉及的数据表、种子、清理和快照范围。
- 每个 `api-docs/endpoints/*.json` 里的 `endpoint_key` 都应有对应 `tests/*.test.json`。
- 新增、删除或修改接口时，必须同时更新 `api-docs/`、测试文件和必要的数据种子。
